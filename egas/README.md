# EGAS 3D — Laboratório conceitual

Este diretório contém uma visualização 3D educacional do conceito EGAS, integrado ao projeto S.P.E.C.T.R.A.

## Abrir
Com GitHub Pages habilitado para a branch `main` e a pasta `/(root)`, o endereço será:

`https://ehnoixx.github.io/projeto-192-nuclear-simulator/egas/`

## Recursos
- Visualização 3D com órbita, zoom e seleção por clique.
- Alternância independente de camadas.
- Seleção de componentes e ficha descritiva.
- Comparação conceitual de materiais.
- Ajustes visuais de comprimento, diâmetro e transparência em tempo real.
- Indicadores qualitativos de compatibilidade, explicitamente não validados.

## Limites científicos
O elemento de número atômico 192 não foi descoberto. O EGAS é uma arquitetura especulativa. As geometrias, dimensões e índices deste laboratório são recursos didáticos e não representam parâmetros de fabricação, desempenho, segurança ou viabilidade. A pontuação de compatibilidade é heurística e não substitui análise de engenharia.

## Dependências
Three.js 0.160.0 e OrbitControls via CDN. É necessária conexão com a internet para carregar as bibliotecas e fontes.
